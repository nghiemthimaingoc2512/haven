# Haven Brand Guidelines

## Official Mascot

Master asset:

public/brand/master/haven-moon-master.png

This image is the official Haven mascot.

It represents Haven and Aurora.

This mascot is part of Haven's permanent brand identity.

---

## Rules

Never redesign it.

Never redraw it.

Never regenerate it.

Never replace it.

Never create another moon.

Never create another face.

Always derive every Haven brand asset from this image.

---

## Allowed

- crop
- resize
- simplify for small sizes
- remove background
- reduce glow
- export PNG
- export SVG
- export favicon
- create navigation avatar
- create app icon
- create loading mascot
- create onboarding mascot

---

## Forbidden

- new moon
- new face
- new illustration
- different proportions
- different colors
- different personality
- AI-generated replacement mascot

---

Every Haven visual asset must originate from this master mascot.

---

## Rendering Rules

Never modify the mascot through CSS.

Forbidden:

- opacity
- blur
- brightness filters
- saturation filters
- grayscale
- color overlays
- CSS tint
- blend modes
- radial glow
- artificial halo
- backdrop filters

Always render the mascot exactly as exported.

Never alter its appearance.
